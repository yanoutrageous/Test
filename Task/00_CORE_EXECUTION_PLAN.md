# 核心实行计划

## 1. 最终目标

在`D:\AAA命题\Test`内完成一个完全本地、可恢复、可追溯、可直接交付客户使用的高中数学题库与组卷系统。最终成品必须让真实用户通过正常界面完成完整业务流程，不依赖开发者手工改数据库、运行隐藏脚本或临时修补导出文件。

V1 必须同时具备：

1. 组卷蓝图：题型、分值、知识点、方法、难度、年份和预计用时约束；
2. 学生卷、教师卷、答案册、解析册、答题卡一体生成；
3. 几何图、函数图、统计图的 SVG/TikZ 重绘，保留原图双轨；
4. 本地相似题与语义搜索，正式标签坚持人工审核；
5. 模板编辑器、字体校准和视觉回归仪表盘；
6. 数据库、项目内原件、派生资产和导出快照的一键备份恢复。

正式排版以 2020—2025 新课标 I、II 卷数学试卷汇编及适应性测试卷的视觉风格为主目标，并达到阶段金标定义的“视觉近一比一”标准。

## 2. 成功不等于功能存在

每项能力必须同时满足：

- 正常流程可用；
- 边界输入可控；
- 失败时有可理解提示；
- 可取消、可恢复、可重复运行；
- 数据和来源可追溯；
- 不越出文件系统安全边界；
- 有真实用户流程证据；
- 有操作手册和故障恢复手册；
- 断网环境可运行；
- 新用户无需接触源码即可完成核心业务。

任何“接口存在但 UI 走不通”“测试构造数据可过但真实资料失败”“PDF 能生成但版式不可用”“备份有文件但恢复未演练”的状态，都不能算完成。

## 3. 范围边界

### V1 范围内

- 单机、本地、个人或单操作员工作流；
- 结构化题库、来源追溯和人工复核；
- 目标真题与代表性模拟卷的可复现导入；
- 高保真正式 PDF 和浏览器快速预览；
- 本地全文、结构化和语义混合检索；
- 人工审核标签与解析证据；
- 五类文档一致生成；
- 图形原图/矢量双轨；
- 完整本地备份、恢复和发布快照。

### V1 暂不作为发布门禁

- 多人协作、账号权限、云同步和公网服务；
- 自动向外部平台发布或分发原卷；
- 任意低质量手机照片的全自动无人工 OCR。

任意图片导入必须在数据模型、来源坐标、变换链和人工复核接口中预留扩展位；V1 稳定后可作为首要增量功能，不能以此为由破坏当前主链路。

## 4. 里程碑总览

| 里程碑 | 覆盖阶段 | 核心结果 |
|---|---|---|
| M0 | 安全基线、金标、领域模型与 IR | 系统知道“能写哪里、什么是正确、数据如何版本化” |
| M1 | 题库生产线、高保真排版 | 一份真实完整试卷能可追溯入库并稳定高保真重建 |
| M2 | 蓝图求解、五类文档 | 一个蓝图能生成相互一致的完整文档包 |
| M3 | 图形双轨、标签检索、模板回归 | 图形、智能检索和模板维护形成可用闭环 |
| M4 | 完整备份恢复 | 故障后能从备份在 staging 中完整恢复并安全切换 |
| M5 | 全量与客户交付 | 目标汇编、全用户流程、离线包和交付文档全部通过 |

## 5. 关键路径与可并行项

关键路径：

```text
M0 安全与金标
→ M1 真实题库与排版
→ M2 蓝图与五类输出
→ M3 综合能力
→ M4 恢复能力
→ M5 全量交付
```

在 M0 数据合同稳定后，可并行推进语义索引试验、备份原型和视觉基线工具；但并行结果必须在对应里程碑统一合流验收。共享工作区同一时刻只允许一个写入者。

## 6. 每个工作切片的固定闭环

```text
读取规范与 RUN_STATE
→ 冻结范围和禁止项
→ 依赖与磁盘预检
→ 建立检查点
→ 在副本/staging 实现
→ 运行分层测试
→ 跑相关真实用户流程
→ 安全与边界审计
→ 更新证据、风险和 RUN_STATE
→ 显式提交并阶段 push
```

失败时保留候选和证据，修复实现；不得删除失败测试、降低门槛、重置视觉金标或覆盖活动版本。

## 7. 可调整与不可调整事项

### 可以经 ADR 调整

- 内部库、UI 组件和模型实现；
- 表结构细节和索引组织；
- 模板参数与视觉阈值的校准值；
- 不破坏依赖关系的阶段内顺序；
- 可重建派生资产的存储格式。

### 不可自行调整

- 项目数据唯一写根、Test 外参考只读和依赖安装窄例外；
- 原件不覆盖、删除先隔离；
- 本地处理和不上传业务资料；
- 正式标签人工审核；
- 五类文档同源一致；
- 备份必须实际恢复演练；
- 最终必须跑通真实客户流程；
- 不得以测试数量或代码覆盖率替代用户可用性；
- 不得静默放宽蓝图硬约束、字体替换或验收门槛。

## 8. 完成判定

长期目标只有在以下事实同时成立时才完成：

1. M0—M5 均有阶段报告、测试证据、安全证明和普通 Git 推送记录；
2. 目标题库和目标汇编可从项目内事实数据重建；
3. 五类文档在真实数据上题号、分值、答案和来源 100% 对应；
4. 视觉金标、字体校准、图形语义和搜索金标通过；
5. 完整备份已在 staging 恢复并重新跑通固定用户流程；
6. fresh-user 环境中断网启动并完成端到端业务；
7. 项目/运行时 Test 外写入审计为零；依赖包管理器事务另有独立 manifest；
8. 客户交付清单、使用手册、限制说明和恢复手册齐全；
9. 不存在未披露的 P0/P1 风险或伪造、缺失的验收证据。
