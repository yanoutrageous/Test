## 直接使用

1. 进入 `output/releases/LOCAL-EXAM-BANK-1.0.0-RC2`。
2. 可先运行 `launcher\verify.cmd` 做完整性、依赖、数据库和模板检查。
3. 双击 `launcher\start.cmd`，浏览器访问终端显示的
   `http://127.0.0.1:8765/`。
4. 首次启动解压约 32.2 MB 的固定离线 Python 运行时；以后直接复用。
5. 外部电子原生 PDF 可从启动器或 CLI 导入。导入会先复制到产品根
   `Copy/source/`，自动结果进入 `pending` 复核队列，不覆盖外部原文件。

- 可迁移本地运行：根目录由标记和项目相对路径确定，不再绑定 D/E 盘或用户名。

  `pending/reviewed/approved` 状态流。

## 后续时间和空间

日常使用不会重复构建 RC、执行 583 项全量门禁或复制多个 fresh-user 产品目录。
首次启动只解压一次离线运行时，随后复用。正常增长主要来自用户导入的来源副本、
页面图、导出文档和用户主动创建的备份；应用不会每次运行自动生成本次开发验收规模的
测试沙箱。只有应用、依赖、发行内容或安全边界发生变化时，才需要重新构建和完整验收。
