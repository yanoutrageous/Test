# 需求—测试—证据追踪矩阵

| Requirement ID | 来源 | 用户结果 | 风险 | 验收条件 | 自动测试 IDs | 用户旅程 IDs | 数据/金标 | 证据 | Commit | 状态 |
|---|---|---|---|---|---|---|---|---|---|---|

状态仅允许：NOT_STARTED / IN_PROGRESS / FAIL / BLOCKED / PASS。

完成一项需求至少需要：

- 确定性规则自动测试；
- 一条真实正常用户旅程；
- 一条匹配风险的失败/恢复/安全旅程；
- 证据绑定确切 commit、数据和版本；
- 所有未验证项明确为未完成。
