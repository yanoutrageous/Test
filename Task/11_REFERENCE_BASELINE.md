# 参考资产与金标基线计划

## 1. 只读盘点摘要

只读参考根目录`${REFERENCE_ROOT}`（本机授权值为项目目录的父目录）约有 1,500 个有效参考文件，总体约 2.6 GiB，主要包括 569 个 DOCX、435 个 PDF、259 张 JPG、54 个 SVG 和 16 份 XLSX。参考库必须按角色取样，不能整体复制、整体入库或整体作为测试夹具。

本文件只保存可公开提交的逻辑 ID 与脱敏特征。本机绝对路径和私人文件名保存在 Git 忽略的`Task/local/REFERENCE_PATHS.local.md`；Git 报告、PR 和客户包不得复制该映射。

重要区分：

- 视觉真值：用于测纸张、分页、字体外观和图形位置；
- 内容真值：用于题目文本、来源和搜索；
- 评分/解析真值：用于答案册、解析册和标签证据；
- 图形真值：用于 FigureIR、SVG/TikZ；
- 测量学数据：用于实测难度和区分度，必须脱敏；
- 失败真值：必须被系统安全拒绝或进入复核。

同一文件不能因视觉相似就自动成为结构化内容真值。

## 2. 核心视觉目标

### NEW9

逻辑 ID：`REF-VIS-NEW9`

- 91 页；1 页 A4，90 页约 182×257 mm；
- 无可提取文本层和可识别字体；
- 部分页面含栅格图，大量正文为矢量轮廓；
- 是 B5 汇编视觉主金标，不是结构化文本真值；
- 必须做整页栅格、锚点、分页和人工叠图；
- 精确字体不能从该 PDF 可靠恢复，需字体校准或声明视觉等效。

金标页应覆盖：封面、目录、普通题页、1/2/4 栏选项、跨页解答题、复杂公式、几何图、函数/统计图、表格和不同卷间分页差异。

## 3. 核心内容真值

逻辑 ID：`REF-CONTENT-HISTORY`

- 约 1207 页、420×297 mm 横向；
- 约 179 万可提取字符；
- XeTeX 生成，含 STSong、STHeiti、Latin Modern 等字体线索；
- 适合题目来源追溯、全文搜索和结构抽取；
- 不作为 NEW9 版式金标。

内容提取必须和对应原题/来源页人工核对，不能因为有文本层就默认公式或阅读顺序完全正确。

## 4. 可编辑模板与排版规则

### 试卷模板

逻辑 ID：`REF-TEMPLATE-PAPER`

- 184×260 mm；上下边距约 20 mm、左右约 22 mm；
- 主要宋体、黑体、Times New Roman；
- 包含卷头、注意事项、题型分区和页眉页脚；
- 用作可编辑 B5 模板，不等同于 NEW9 的 182×257 mm。

### 答案模板

逻辑 ID：`REF-TEMPLATE-ANSWER`

- A4；包含评分说明、答案表和解析结构；
- 出现方正书宋简体、汉仪中黑简、宋体、黑体和 Times New Roman；
- 用于答案/评分模板；商业字体必须完成许可和替代审计。

### 排版要求

逻辑 ID：`REF-LAYOUT-RULES`

- 记录五号字、MathType、1.5 倍行距、公式不上浮/下沉、宋体/Times New Roman 及解析格式；
- 作为历史人工排版规则输入，需转为结构化模板 token；
- 其中规则若与 NEW9 金标冲突，分别建立模板族，不强行合并。

### A4/B5 重排样本

逻辑 ID：`REF-EDITABLE-PAPER-SET`

- 前两份偏 A4 大边距，2025 样本为 184×260 mm；
- 大量使用 WMF 和 MathType OLE，而非原生 OMML；
- 用于验证历史 Office 资产的规范化和长期兼容风险。

## 5. 一体化五件套金标

逻辑 ID：`REF-FIVE-ARTIFACT-GOLD`

包含：

- B5/紧凑学生卷及 A4 版；
- 参考答案；
- 详解详析与命题人分析；
- A3 两页答题卡；
- A4 六页答题卡；
- 多轮排版历史版本。

已知异常：详析 PDF 实际 63 页，但页脚显示“共62页”。该异常必须作为视觉/页码一致性失败样本，系统不得复刻错误后声称通过。

详析 DOCX 含大量表格、媒体和 OLE 对象，适合解析册压力测试。答题卡主要为轮廓矢量、无文本层，必须使用视觉比较。

补充简洁答题卡/评分模板：

逻辑 ID：`REF-ANSWER-SHEET-GOLD`、`REF-SCORING-GOLD`

## 6. 杂乱来源与导入压力样本

逻辑 ID：`REF-MESSY-DOC-SET`、`REF-PHOTO-INPUT-SET`

- 覆盖 OLE/媒体/字体混杂的 Word；
- 覆盖低分辨率手机照片、透视、阴影、模糊、弯曲和手写痕迹；
- V1 仅要求安全导入、来源/变换 IR 和人工复核接口，不要求照片全自动正确；
- 不支持或低置信输入必须明确进入复核/拒绝状态。

## 7. 图形金标与失败样本

高价值样本：

逻辑 ID：`REF-FIG-STAT-SET`、`REF-FIG-GEOMETRY-SET`、`REF-FIG-SOLUTION-SET`

覆盖统计图、解析几何、立体几何、原图、辅助线和建系演进。

失败样本：

逻辑 ID：`REF-FIG-BROKEN-SVG`

该文件存在非法 XML/重复属性，应被验证器拒绝；`fixed`和`tight_margin`版本应通过。还需补充脚本、外链和`foreignObject`的合成攻击夹具。

## 8. 标签证据参考

逻辑 ID：`REF-TAG-EVIDENCE-SET`、`REF-METHOD-ANALYSIS`

- 含历年试题分析、教育部考试院相关分析和方法性材料；
- 部分为扫描页无文本层，只能作为人工证据源；
- 作者观点不能等同官方正式标签；
- 首批标签金标应覆盖主要知识点、方法和解析依赖标签，并记录题目 revision、证据页/步骤、审核人和 taxonomy release；
- 初始数量服从覆盖矩阵，不以固定条数替代质量。

## 9. 成绩和测量学参考

现有约 16 份 XLSX 含姓名、学号、进入/交卷时间、IP、总分和逐题得分。两套 HTML 原型计算难度 P、区分度 D、Cronbach α 和图表，但引用远程 CDN。

用途：

- 脱敏副本可核对 P、D、α 和整卷完成时间；
- 实测数据不能覆盖人工预计难度；
- 当前表格不提供可靠逐题停留时间，不能构造`observed_item_time`；
- HTML 只作为交互/指标原型，生产实现必须本地依赖、CSP、无外部脚本；
- 原始表不得进入 Git、embedding、普通日志和客户包。

## 10. 模板族

V1 至少建立：

1. NEW9 仿真 B5：182×257 mm；
2. 可编辑 Word B5：184×260 mm；
3. 紧凑成卷：176×250 mm；
4. 官方/重排 A4；
5. 学生卷/教师卷 B5 长短版；
6. A4/B5 答案与评分标准；
7. A3 双页和 A4 多页答题卡；
8. 长篇解析与命题人分析册；
9. A4 教案/讲义；
10. A3 横向真题汇编页；
11. 题干原图、规范重绘、解答辅助线三轨图形；
12. 本地测验质量分析仪表盘。

模板族可以共享 token，但不能用一个参数模板硬撑所有尺寸和排版习惯。

## 11. 金标登记要求

每个金标记录：

- logical ID、本机受忽略映射中的来源路径和 Test 内副本；
- SHA-256、大小、页数、页面尺寸；
- 真值角色；
- 覆盖的需求/风险；
- 人工确认人和日期；
- 字体/许可/PII 分类；
- 预期成功、复核或拒绝结果；
- 变更原因和历史版本。

提交到 Git 的登记只含 logical ID、Test 内逻辑相对路径、脱敏摘要和必要哈希；外部绝对路径与私人文件名只留在本地受忽略映射。

金标更新是 D2 高风险操作，必须独立审计。不得由被测实现自动更新。
