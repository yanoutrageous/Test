# ADR 0001：正式 PDF V1 采用源页组合

- 状态：Accepted
- 日期：2026-07-25
- 适用阶段：M1

## 背景

M1 需要把一份真实完整试卷从 Copy 导入、复核并生成稳定正式 PDF。该试卷包含中文、数学符号和多种内嵌字体；重新排版会引入分页、字形替换和公式位置漂移。项目同时要求可迁移、低磁盘增量和确定性复现。

## 决策

正式 PDF V1 使用 `SOURCE-PAGE-COMPOSITION-V1`：

- PaperIR 冻结题号、分值、题目 revision、模板 revision 和源页数量；
- 正式学生卷按完整源页序列组合，当前实现对已验证源 PDF 做字节保持；
- 原貌页、题目裁切和结构化 QuestionIR 作为独立轨道保存；
- 所有路径均为项目内相对路径，Copy 哈希、模板 revision、产物哈希和数据库状态由 manifest 绑定；
- 字体缺失、页数不符、像素差异或未嵌入字体均失败关闭。

## 结果

优点：

- 源页几何、字体、矢量内容和分页不会漂移；
- 同一输入、版本和参数得到相同字节；
- 不依赖新电脑上的系统字体；
- 每次真实整卷仅增加数 MB，避免生成大型中间缓存。

限制：

- V1 正式 PDF 不是可编辑重排版；
- 结构化文本用于检索、复核和后续文档投影，原貌图仍是版式事实来源；
- 未来如引入 Typst/LaTeX 结构化正式渲染器，必须新建 ADR、模板 revision 和视觉基线，不能静默替换本决策。
