# 已知限制

- 当前已审核数据只有一份完整 19 题、150 分代表卷；尚未完成 2020—2025 新课标 I/II
  与适应性测试全目标集的逐题生产和人工复核。
- 目标 NEW9 汇编缺少可用文字层；V1 不包含扫描件 OCR、公式 OCR 或 AI 全自动解析，
  因而不能用自动化结果冒充人工审核完成。
- 随包来源派生内容和嵌入字体只允许源资料权利人私有本地使用，不是可公开再分发版本。
- 备份与产品位于同一卷，不抵御整盘故障。
- 本地“语义”能力采用冻结的哈希 TF-IDF 模型，不是在线大模型，不支持任意自然语言
  推理。
- 自动验收完成 PDF 打开、渲染与打印预览，不操作真实打印机，也不声明特定驱动和纸张
  已实机验证。
- 普通 Windows 账户无创建目录 symlink 的权限；系统仍拒绝现有 Reparse Point，但未
  通过需要 WinError 1314 权限的“真实创建 symlink”能力探针。

以上限制不影响当前代表数据上的题库、复核、搜索、蓝图、五类输出、图形/模板和
备份恢复使用，但阻止把本候选描述为“全目标集、可公开分发的最终正式版”。
