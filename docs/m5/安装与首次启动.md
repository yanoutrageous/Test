# 安装与首次启动

本产品是 Windows 11、64 位、NTFS 本地应用。运行时、题库和所有可变数据都保存在
产品根目录内；目录可整体迁移到其他本机 NTFS 盘符或普通父目录。

1. 保持整个产品目录完整，不拆分 `app`、`runtime`、`data` 等子目录。
2. 双击 `launcher\start.cmd`。
3. 首次启动会在产品根内解压随包附带的 Python 运行时到 `.runtime`，不访问网络，
   不写注册表、不安装系统服务。
4. 看到 `READY` 后，在浏览器打开 `http://127.0.0.1:8765/`。
5. 结束服务时回到启动窗口按 `Ctrl+C`。

导入带文字层的电子原生 PDF 时，先停止服务，再在 PowerShell 中执行：

```powershell
$pdf = (Resolve-Path .\待导入\试卷.pdf).Path
launcher\start.ps1 -ImportPdf $pdf -Pages "1-2" -Columns 1 -Year 2024 -Title "2024 年试卷"
```

`-Pages` 使用 PDF 文件中的页码；多栏汇编可把 `-Columns` 调整为实际栏数。系统先把原文件
复制为产品根内的受控副本，再生成页面图和待复核题目；不会改写外部原文件。导入成功后重新
启动服务，在“题库与复核”中逐题确认。导入结果默认是 `pending`，不会自动进入正式组卷池。

首次启动失败时，先运行 `launcher\verify.cmd`。检查不会修改题库；它会核对根标记、
运行时归档、依赖版本、活动状态、可用空间和必要文件。

不要把产品目录放在盘符根、网络共享、云同步目录、Reparse Point、符号链接或启用了
不透明重定向的目录中。迁移前先关闭服务并确认没有正在运行的备份、恢复或导出作业。
