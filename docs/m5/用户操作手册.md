# 用户操作手册

首页是所有正式能力的入口。

- **PDF 导入**：服务停止时通过 `launcher\start.ps1 -ImportPdf ... -Pages ...` 导入带文字层的
  电子原生 PDF。导入内容先进入待复核队列，原文件保持只读不变。
- **题库与复核**：查看题面、原貌裁图、来源、revision 和审核状态；保存后再进入正式
  搜索与组卷。
- **检索与相似题**：支持关键词、年份、题型、分值、知识点以及本地相似度检索。结果
  会显示命中原因，不访问在线模型。
- **蓝图与组卷**：先求解蓝图，再锁题、换题和排序；不可行条件会返回具体缺口，不会
  伪造成功试卷。
- **标签审核**：候选标签必须绑定证据并人工批准；解析改变后相关状态会过期。
- **图形与模板**：可查看原图、SVG、TikZ 和已批准模板；失败的视觉回归不能覆盖当前
  模板。
- **五类文档**：同一冻结试卷提供学生卷、教师卷、答案册、解析册和答题卡。
- **备份与恢复**：备份完成验证后才可选择；恢复先进入 staging，通过后还需显式激活。

学生卷不含答案和解析。五类 PDF 已完成程序化打开、分页、映射和本地渲染检查；实际
打印前仍应在浏览器或 PDF 阅读器中确认纸张、缩放和单双面设置。

当前随包题库是已验收的一份 19 题、150 分代表卷。外部真实电子 PDF 的受控导入、三栏切题、
待复核、页面原貌查看、人工改为 `reviewed`、备份恢复及重启保留均已通过全新用户验收。它仍
不应被误称为已经完成 2020—2025 全部目标卷的逐题人工复核。
