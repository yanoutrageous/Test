# 模板与字体说明

当前批准模板为 `TEMPLATE-M3-EDITABLE-B5-REV-002`，对应受控参考
`排版格式-试卷.docx` 的 184×260 mm 纸张、左右 22 mm、上下 20 mm 基线。学生卷与教师卷
均按该纸张族输出；答案册、解析册和答题卡保留各自既有纸张族。模板参数、视觉基线和字体状态
均有 revision；
校准失败只生成候选，不会自动替换已批准版本。

发布包保留该参考原件的逐字节副本及路径脱敏 provenance，位置是
`templates/reference/排版格式-试卷.docx`。它用于人工核对版式，不表示系统会把组卷结果
回写成 DOCX；正式输出仍是五类就绪 PDF。

交付包不包含可独立安装或复制的商业字体文件。现有代表 PDF 使用来源文件中已嵌入的
子集字体字节完成本地重建，字体 manifest 将其标为 `user-provided`、
`redistributable=false`。因此：

- 本包只供源资料权利人本人在本机或其迁移电脑上使用；
- 不得把来源派生 PDF、嵌入字体或题目资产再分发给第三方；
- 若需制作可对外分发版本，必须替换为许可明确允许再分发的字体和内容，并重新运行
  字体校准、视觉回归和五类文档门禁；
- 字体缺失或哈希不符时系统应阻止正式激活，不做静默替换。
