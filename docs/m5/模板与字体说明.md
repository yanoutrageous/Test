# 模板与字体说明

当前批准模板为 `TEMPLATE-M3-B5-REV-002`。模板参数、视觉基线和字体状态均有 revision；
校准失败只生成候选，不会自动替换已批准版本。

交付包不包含可独立安装或复制的商业字体文件。现有代表 PDF 使用来源文件中已嵌入的
子集字体字节完成本地重建，字体 manifest 将其标为 `user-provided`、
`redistributable=false`。因此：

- 本包只供源资料权利人本人在本机或其迁移电脑上使用；
- 不得把来源派生 PDF、嵌入字体或题目资产再分发给第三方；
- 若需制作可对外分发版本，必须替换为许可明确允许再分发的字体和内容，并重新运行
  字体校准、视觉回归和五类文档门禁；
- 字体缺失或哈希不符时系统应阻止正式激活，不做静默替换。
