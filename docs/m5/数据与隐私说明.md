# 数据与隐私说明

应用仅监听 `127.0.0.1` 或 `::1`，正式启动默认启用非回环连接拒绝门。没有 CDN、
遥测、远程字体、在线 embedding/LLM 或业务上传。

数据库、用户状态、备份、恢复 staging、导出和日志均位于产品根内。业务 manifest
只保存项目相对路径或对象 ID，不保存电脑盘符、用户名和外部资料绝对路径。

交付构建会阻止以下内容进入发布包：Git 凭据、token、cookie、浏览器配置、`.venv`、
缓存、失败导出、Base 原卷、外部绝对路径以及姓名、学号、IP、QQ 等常见个人信息。

当前包的内容授权范围是“源资料权利人私有本地使用和整根迁移”。在向第三方提供副本
前，必须重新审计题目、解析、图形、模板和字体的分发许可，并重建 release manifest。
