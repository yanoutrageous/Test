# 故障排查

先运行 `launcher\verify.cmd`，按中文失败项处理。

- **根目录无效**：把完整产品目录移到本机 NTFS 普通目录；不要放在盘符根、网络共享、
  符号链接或 Reparse Point 下。
- **运行时归档哈希不符**：停止使用该副本，从原始发布包重新完整复制；不要混合补文件。
- **端口 8765 被占用**：关闭占用程序，或在 PowerShell 中运行
  `launcher\start.ps1 -Port 8766`。
- **空间不足**：停止新备份/恢复，把已明确判定为被替代的测试证据可恢复地迁出产品盘；
  不要清空 `backups`、`data\exports`、`data\originals` 或活动状态。
- **备份不可选择**：查看验证错误；损坏、缺文件、越界和旧 schema 备份会被拒绝。
- **恢复后页面仍显示旧状态**：正常关闭并重新启动服务，确认首页活动状态 ID 已改变。
- **字体或视觉门失败**：保留上一批准模板，按“模板与字体说明”补齐许可明确的字体后
  重新校准；不要降低阈值或覆盖金标。

所有核心功能均离线。若看到应用尝试访问非回环地址，应立即停止并保留日志，这属于
发布阻断问题。
