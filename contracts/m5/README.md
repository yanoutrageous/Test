# M5 私有本地 RC 合同

`m5-private-local-rc-v1.json` 记录 RC2 的两个不同结论：

- `ACCEPTED_SUPPORTED_PRIVATE_RC_SCOPE`：资料权利人可直接离线使用并整根迁移
  `LOCAL-EXAM-BANK-1.0.0-RC2`。
- `BLOCKED_DISCLOSED`：2020—2025 全目标集、第三方分发许可和真实打印机验证尚未完成，
  因而不把私有本地 RC2 误报为公开发行正式版。

RC2 已加入电子原生 PDF 的本地半自动导入、题目复核队列，以及
`排版格式-试卷.docx` 的受控 184×260 mm 排版模板。合同绑定发行包、真实新用户验收、
583 项最终门禁、写入口清单及 E 盘可恢复清理结果。

纯报告或状态更新不重复运行全量门禁；只有应用、依赖、发行内容或安全边界变化时，
才重新构建并执行完整验收。
